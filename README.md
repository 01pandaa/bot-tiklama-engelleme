# Bot Tıklama Engelleme

Google Ads reklamlarında şüpheli, bot ve tekrarlayan tıklamaları analiz etmek için geliştirilen sistem.

## Amaç

- Tıklamaları takip etmek
- Şüpheli davranışları tespit etmek
- IP adreslerini analiz etmek
- Bot trafiğini belirlemek
- Şüpheli IP'leri listelemek
- Reklam bütçesinin kötüye kullanımını azaltmak
- İleride Google Ads entegrasyonu yapmak
